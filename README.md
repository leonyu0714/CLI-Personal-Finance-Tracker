# CLI-Personal-Finance-Tracker

## Proposal Report

### 1. Project Title
CLI Personal Finance Tracker

### 2. Motivation and Goal
This project aims to build a command-line personal finance tracker that helps users record daily income and expenses.  
The goal is to provide a simple and efficient tool for managing personal financial records, searching past transactions, and analyzing spending habits.

### 3. Expected Features
- Add income or expense records
- Delete or modify existing records
- Search records by date, category, or keyword
- Sort records by date or amount
- Show financial summaries such as total income, total expenses, and balance
- Save data to files and load data from files

### 4. Technologies / Programming Language
- C++
- Command-line interface (CLI)
- File input and output
- Object-oriented programming

### 5. Initial Development Plan
- Week 7: Finish project proposal and system design
- Week 8-9: Implement basic data structure and add/view record functions
- Week 10-11: Implement search, sort, and summary functions
- Week 12: Implement file saving/loading
- Week 13+: Testing, bug fixing, and improving code structure

### 6. Related Data Structures / Algorithms
This project may involve the following concepts:

- Dynamic array / vector:
  Used to store multiple financial records efficiently.
- Searching:
  Used to find records by date, category, or keyword.
- Sorting:
  Used to arrange records by date or amount.
- Structures / classes:
  Used to organize each financial record clearly.
- File handling:
  Used to store records persistently for future use.

These concepts are closely related to data structures and advanced programming because the project requires efficient data organization, manipulation, and retrieval.
